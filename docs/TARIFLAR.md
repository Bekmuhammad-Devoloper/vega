## Hisoblash asosi

**Modellar va narxlar:**

| Operatsiya | Model | Narx |
|---|---|---|
| AI auto-fill (matn) | `gpt-4o-mini` | $0.15/1M input + $0.60/1M output |
| AI rasm generatsiya | `gpt-image-1` standard 1024×1024 | $0.04/rasm |
| AI rasm yaxshilash (edit) | `gpt-image-1` edit | $0.04/rasm |

**Bitta auto-fill o'rtacha sarfi:** ~300 input + ~600 output token (UZ+RU tilda)
= `(300×0.15 + 600×0.60) / 1M ≈ $0.0005/fill` (buffer bilan)

> ⚠️ Real ishlatishda retry, rate-limit va system promptlar uchun **+30% buffer** kiritish tavsiya etiladi.

# 📌 Eslatmalar

1. **Rasmlarni Cloudflare R2 / S3'ga** chiqarish majburiy — aks holda Pro/Premium do'konlar serverni "yeb" qo'yadi.
2. **Backup'ni majburiy tashqari** chiqaring (Backblaze B2 = $0.005/GB).
